# 沼に焚べ

疑似3D視点のベルトアクションゲーム。奥行きを持つ2D表現でのアクションを目指した作品。

## 動作環境

- OS: Windows 10 / 11
- [Siv3D](https://siv3d.github.io/) v0.6.16

ビルドに必要なツールとセットアップ手順は [docs/SETUP.md](docs/SETUP.md) を参照。
