# 会話システム

## テキスト表示

1文字ずつ表示されるタイプライター方式。

## テキスト管理

テキストは外部ファイル（JSONなど）で管理し、ハードコードしない。多言語対応が必要になった際に対応しやすくするため。

## UI

キャラクターの吹き出しとして表示する。画面下部に固定するUIは持たない。

## 選択肢

選択肢を2種類の目的で使い分ける。

| 種類 | 用途 |
|------|------|
| ストーリー分岐 | 選択によってその後の展開や台詞が変化する |
| 雰囲気の選択 | どれを選んでも結果は同じだが、返答の雰囲気が変わる |

## 操作

キーボード・マウス、およびコントローラの両方に対応する。

| アクション | 入力 |
|------|------|
| 会話開始（コントローラ） | NPCに近づいた状態で決定ボタン |
| 会話開始（キーボード・マウス） | NPCに近づいた状態でNPCをクリック |
| テキスト全文表示 | 決定ボタン（タイプライター表示中に） |
| 次の台詞へ進む | 決定ボタン（全文表示後に） |
| 選択肢を選ぶ | 方向入力 ＋ 決定ボタン |
