# ステージ構造デザイン

## マップ表現方式

バトルパートと共通。[battle_design.md](battle_design.md) 参照。

---

## ステージ間の構造：拠点ベース（ハブ型）

```
         ┌──────────────────────┐
         │       拠点（ハブ）      │
         │  NPC / 出発 / 帰還    │
         └──────┬───┬───┬───────┘
                │   │   │
       ┌────────┘   │   └────────┐
       ▼            ▼            ▼
  [エリア A]    [エリア B]    [エリア C]
  序盤ステージ群  中盤ステージ群  終盤ステージ群
       │            │            │
  NPC出現/イベント  NPC出現/イベント  NPC出現/イベント
```

- プレイヤーは拠点から任意のエリアを選んで出発する
- エリアをクリアすると拠点に帰還し、次のエリアを選択できる

---

## ステージ内の流れ

```
スタート地点 → 戦闘 → NPC会話/分岐 → 戦闘 → ゴール
```

- ベルトスクロール形式で左から右へ進行
- 道中に敵の群れ、NPCとの遭遇が差し込まれる
- NPCとの会話はストーリー進行・世界観補完を担う

---

## NPCイベントの役割

探索パートにおける唯一の非戦闘インタラクションとして、以下を担う：

- **世界観の補完**：拠点・エリアの背景・住人の事情を語る
- **ストーリー前進**：次のエリアへの動機やヒントを提供する
- **感情的なアクセント**：戦闘の合間に緩急をつける

NPCはエリア内の特定地点に出現する形式を想定。
会話後に選択肢による分岐が発生する設計とする（ストーリー設計と連動）。
会話システムの詳細は [dialogue_system.md](dialogue_system.md) 参照。

---

## 拠点（ハブ）の機能

| 機能 | 内容 |
|------|------|
| 会話 | NPCとの対話。ストーリーや世界観の補足を行う |
| ステージ選択 | 出発するエリアをここで選ぶ |
| 練習 | バトルを自由に練習できる場所 |
