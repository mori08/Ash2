# バトルパート 設計メモ

## 画面・視点

- ベルトスクロール風
- 内部は3D座標で処理、描画は2D（奥行きと高さをY軸に統合）
- プレイヤーキャラクター1人を操作

---

## 攻撃システム

### 通常時

| 種類 | 内容 |
|------|------|
| 近距離攻撃 | 格闘系（パンチ・キックなど） |
| 遠距離攻撃 | 弾を撃つ／投げる |

近距離・遠距離を状況に応じて使い分けることで、位置取りと立ち回りに戦略性が生まれる。

### 変身システム

| 項目 | 内容 |
|------|------|
| 種類 | 2種類（近距離強化モード／遠距離強化モード） |
| 発動方法 | 近距離攻撃ボタン長押し→変身1、遠距離攻撃ボタン長押し→変身2 |
| 発動条件 | いつでも可。スタミナゲージを大量消費 |
| 変化内容 | 近距離・遠距離どちらの技も全面切り替わり |
| スタミナ回復 | 時間経過で自然回復 |
| 任意解除 | なし（スタミナ切れで強制解除） |

変身中は使える技・攻撃が全面的に切り替わる。「いつ変身するか」がバトルの緊張感と爽快感の中心。

#### 入力設計

攻撃ボタンを押した瞬間に攻撃が発動し、そのまま押し続けて閾値を超えると変身が発動する。
攻撃と変身が同一ボタンの「短い操作・長い操作」として自然に流れる設計。

> **コンセプト：** 高さと速さ。ベルトアクションの制約（奥行きと高さが同軸）を逆手に取り、影などの演出で高さを分かりやすく表現しながら、縦方向の動きと超高速の動きを派手さの核にする。

### 変身モード1（近距離攻撃長押しで発動）

**コンセプト：空中にいる敵へ一気に近づく高速接近戦モード**

| ボタン | 通常時からの変化 | 詳細 |
|--------|-----------------|------|
| 近距離攻撃 | → 突進攻撃 | 向いている横方向 or ロック中の敵へ、無敵状態で突進 |
| 遠距離攻撃 | → 落下攻撃 | 地面に向かって無敵状態で急落下しながら攻撃 |
| ジャンプ | → 上昇攻撃 | 急上昇しながら攻撃 |
| 回避 | → 斜め上方向への移動 | 回避方向が斜め上に変化 |

### 変身モード2（遠距離攻撃長押しで発動）

**コンセプト：空中から地上の敵を制圧する滞空・全方位攻撃モード**

常時：落下速度が低下する

| ボタン | 通常時からの変化 | 詳細 |
|--------|-----------------|------|
| 近距離攻撃 | → 全包囲攻撃 | 自分の周りに弾を回す近距離全方位攻撃 |
| 遠距離攻撃 | → 追尾攻撃 | 相手を高速で追尾する遠距離攻撃 |
| ジャンプ | 変化なし | 落下速度低下により、通常より高く・滞空時間が長い |
| 回避 | → 斜め下方向への移動 | 回避方向が斜め下に変化 |

## ロック（遠距離照準）システム

### コントローラー（右スティック）
- ロック中の敵（いなければ自機）を軸に、スティックを倒した方向の敵を**半ロック**状態にする
- スティックを離すと半ロック中の敵を**ロック確定**
- 敵がいない方向にスティックを倒して離すと**ロック解除**
- 一度ロックすると敵が移動しても自動追尾するため、ロックし続けるのが楽

### マウス（カーソル）
- カーソルが敵に重なると**自動でロック確定**
- カーソルが外れると**ロック解除**
- より直感的に狙いを定められるが、敵の移動に合わせてカーソルを動かし続ける必要がある
- ロック判定には実際の見た目より**大きめの円**を使用する
  - ロックに入りやすく、かつ簡単には外れないようにするUX上の工夫
  - ロック開始判定とロック解除判定で円のサイズを変える（入る時は大きく、外れる時はさらに大きく）ことも検討余地あり

### デバイスによる操作感の違い（意図的な設計）

| | コントローラー | マウス |
|---|---|---|
| ロック方法 | スティックで方向指定→離してロック確定 | カーソルを敵に重ねると自動ロック確定 |
| 維持の手間 | 楽（自動追尾） | やや大変（手動で追う） |
| 直感性 | やや間接的 | 直感的 |

> **設計経緯：** マウス操作を先に設計し、コントローラーで再現する際に「ボタン押しでロック確定」を検討したが、アクション中にボタンを押す余裕がないため、スティックを離した瞬間に自動確定する方式に簡易化した。マウス側も同様に、ロック確定の専用アクションをなくし自動確定にすることで操作をシンプルにした。

## バトルの面白さの軸

- 位置取り・立ち回りの重要性
- 近距離↔遠距離の使い分け
- 変身タイミングの判断（スタミナ管理）
- 防御・ガードシステムは実装しない。回避で対応する方針

### 対応デバイス

- ゲームパッド（XInput基準）
- キーボード＆マウス
- キーコンフィグ対応

|--------|--------|--------|

| 右スティック | ロック（遠距離照準）※上記参照 | — |

| 入力 | 通常時 | 長押し |
|------|--------|--------|

## コンボシステム

### 対象
近距離攻撃のみ。遠距離攻撃はモーション自体が小さいため単調でも問題になりにくい。

### 仕様
- 3段コンボ
- 一定時間内に攻撃ボタンが押されると次の段に進む。時間切れでリセット。

| 段数 | モーション | 敵のリアクション |
|------|-----------|----------------|
| 1段目 | モーションA | 小さくひるむのみ |
| 2段目 | モーションB | 小さくひるむのみ |
| 3段目 | モーションC | 吹っ飛び（大きなリアクション） |

### 目的
- **演出**：同じモーションの繰り返しを避け、近距離攻撃に変化をつける
- **敵の反応制御**：3段目のみ大きなリアクションを発生させることで、爽快感とテンポを両立する（毎回吹っ飛ぶと追いかけるのが大変になるため）

## スタミナシステム

### 基本仕様
- 消費直後は回復しない
- スタミナが少ないほど回復量が多い（ピンチほど回復が早い）
- 0になると変身モードは強制解除→通常モードに戻る
- 具体的な数値（消費量・回復速度）は実装しながら調整する

### 消費まとめ

| 行動 | 消費 |
|------|------|
| 近距離攻撃（通常） | 1回ごとに消費。スタミナ量でリーチが変化（満タン→最大リーチ、0→当たらない） |
| 遠距離攻撃（通常） | 1回ごとに少量消費 |
| 変身中（モード1・2共通） | 常時消費＋攻撃ごとに消費 |

### スタミナ管理の戦略性
変身モードは強力だが、使い終わった後はスタミナ0の通常モードで戦わなければならないリスクがある。「いつ変身するか」「どれだけ変身中に攻撃するか」の判断がバトルの緊張感の核になる。

## ヒットストップ

### 基本方針
攻撃した側（自キャラ）と攻撃された側（敵）だけ止める。カメラ・背景・エフェクト・巻き込まれていない他の敵は動き続ける。

| 対象 | 止まる？ |
|------|---------|
| 自キャラ（攻撃モーション） | 止まる |
| 敵（被弾モーション） | 止まる |
| カメラ | 動き続ける |
| 背景・エフェクト | 動き続ける |
| 他の敵（巻き込まれていない） | 動き続ける |

### 例外：変身モードの高速移動中
突進・急落下など高速移動中にヒットした場合、自キャラを止めると気持ちよさが損なわれるため、自キャラは止めずに敵だけ止める。

### コンボとの連動
- 1・2段目：短いヒットストップ
- 3段目（吹っ飛び）：長いヒットストップ

※具体的なフレーム数は実装しながら調整する
