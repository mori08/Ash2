# ROADMAP

各バージョンの目的とスコープのみを定義する。詳細な要件は着手時に Issue で詰める。

---

## alpha版

**目的：** 操作・手触りを検証する（個々のアクション単体の気持ちよさ）

- 基本攻撃・ヒット判定・ダメージ
- 3段コンボ（手触り部分。使い分けの戦略性はbeta以降で検証）
- 回避
- スタミナシステム
- ヒットストップ
- ロックシステム（遠距離照準）
- ダミー敵（動かない）
- コントローラー対応（XInput）

---

## beta版

**目的：** 戦闘ループが成立するか検証する（アクションの組み合わせ・判断が攻防として機能するか）

- 雑魚敵1種とAI
- 1ステージ（スタート〜クリア条件）
- 簡易HUD（HP / スタミナ）

**完了条件：** 変身システムなしでバトルが楽しいと言える状態になっていること（Noの場合、demo着手前にスコープを再検討する）

---

## demo版

**目的：** ゲームの体験を一切り見せられる状態にする

- 変身システム
- 雑魚敵複数種（空中敵含む）・中ボス・ボス1体
- 難易度選択（Easy / Hard）
- 序章〜二章（2〜3ステージ）＋会話システム
- 拠点（ハブ）＋ステージ選択
- NPCイベント
- BGM / SE
- Steam Input API対応（Steam体験版配信）

---

## v1.0

**目的：** ゲームとして完成させる

- 全8章・全ボス5種
- 複数エンディング
- タイトル画面・セーブ
- キーコンフィグ
- ラスボス形態変化
