| ディレクトリ | 内容 | 現行の実装との関係 |
|---|---|---|
| `images/` | EDGE の作業ファイル（`.edg`） | [`Ash2/App/assets/images/`](../Ash2/App/assets/images/) へ書き出した PNG と一致する |

現行の仕様は実装および [docs/](../docs) を参照してください。
