# 命令用 Markdown の書き方

CLAUDE.md・rules・skills・agents など、AI への指示を書く Markdown に適用する。

## 原則

- 短く端的にまとめる
- 命令だけを書き、意図・理由の説明は書かない
- 同じ指示・制御は一箇所に集約し、他の箇所では繰り返さない
- ファイルには表題の対象に関する内容だけを書く。ファイル自身の書き方などのメタ情報は本文に置かない
- 太字や「必ず」などの強調で指示を強めない
- 括弧の補足には本文にない情報だけを書く。指示を裏返して繰り返すだけの括弧（例：「Aを実行する（A以外の手段で解決しない）」）は書かない

## 変更時の確認

- ファイル名・節名・パスを変更したら、参照箇所を Grep で洗い出して同期する
