# テスト

## テスト方針

- 条件：テストを追加・変更する前
- 必読：[docs/TEST_POLICY.md](../../docs/TEST_POLICY.md)（4本柱と判定基準）

テストの価値は次の4つの積で決まる。1つでも 0 に近ければ全体も 0 に近い。

| 柱 | 内容 |
|---|---|
| 1 リグレッションからの保護 | 本物のバグを捕まえる |
| 2 リファクタリングへの耐性 | 挙動を変えない変更で壊れない |
| 3 迅速なフィードバック | 速く回る |
| 4 保守のしやすさ | 読めて、壊れたとき原因がすぐ分かる |

判定基準は「内部だけを変えて挙動を保ったとき、このテストは壊れるべきか」。
壊れるべきでないものに結合しているテストは作り直す。

## 書き方

- 条件：テストファイルを追加するとき
- 必読：[docs/TEST.md](../../docs/TEST.md)（実行方法・実行時の環境・準備コードの置き場所）

1つのテスト対象につき1ファイル、`Test<対象名>.cpp`。別の対象を同じファイルに混ぜない。
